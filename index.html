Cloud Computing

Cloud computing is the pay-as-you-go, on-demand delivery of IT resources via the Internet.
You can use technology services rather than purchasing, owning, and maintaining actual data centers and servers.

Cloud Services

  • AWS Lambda - This is a serverless computing service that automatically executes code in response to events and manages the underlying compute resources.
  • Google Drive - This is a cloud storage and collaboration platform used to store files, synchronize data across devices, and edit documents in real time.
  • Snowflake - This is a cloud-based data warehousing platform used to store, analyze, and query large datasets efficiently across organizations.
